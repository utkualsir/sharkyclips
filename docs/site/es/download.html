Descargar SharkyClips

Un instalador con todo dentro. Sin permisos de administrador, sin programas extra.

Descargar para WindowsGratis · 375 MB · versión 1.2.74Todas las versiones
  • Versión 1.2.74
  • Unos 375 MB
  • Windows 10 / 11, 64 bits
  • Gratis, sin cuenta

Instala en tres pasos

  1. Descarga

    Pulsa el botón de descarga. El archivo se llama SharkyClips-Setup-1.2.74.exe.

  2. Instala

    Ábrelo y pulsa Siguiente y luego Instalar. Tarda alrededor de un minuto. ¿Windows muestra un mensaje azul? Mira abajo.

  3. Primer inicio

    SharkyClips se abre en tu navegador, pregunta tu idioma y revisa tu PC. Luego descarga una vez las partes de IA que encajan con tu PC.

Requisitos del sistema

¿"Windows protegió su PC"?

El instalador aún no está firmado con un certificado de pago, así que Microsoft Defender SmartScreen puede avisar de una descarga nueva. Es normal en apps gratuitas nuevas.

  1. Pulsa Más información.
  2. Comprueba que la app es SharkyClips-Setup-1.2.74.exe.
  3. Pulsa Ejecutar de todas formas.

¿Quieres asegurarte? Cada versión tiene un archivo .sha256. En PowerShell, Get-FileHash SharkyClips-Setup-1.2.74.exe debe mostrar el mismo número.

Actualizaciones

Ajustes → Actualizaciones → Buscar actualizaciones. SharkyClips instala la versión nueva cuando no lo estás usando. Novedades.

Desinstalar

Configuración de Windows → Aplicaciones → SharkyClips → Desinstalar. Te pregunta si también quieres borrar tus ajustes; tus vídeos se conservan.

macOS y Linux

Hay un instalador de un solo comando para macOS y una instalación manual para desarrolladores. Están menos probados que Windows. Mira la guía de instalación.
