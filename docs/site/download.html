Install in three steps

  1. Download

    Click the download button. The file is called SharkyClips-Setup-1.2.74.exe.

  2. Install

    Open it and click Next, then Install. It takes about a minute. Does Windows show a blue message? See below.

  3. First start

    SharkyClips opens in your browser, asks for your language and checks your PC. Then it downloads the AI parts that fit your PC, once.

"Windows protected your PC"?

The installer is not signed with a paid certificate yet, so Microsoft Defender SmartScreen may warn about a new download. This is normal for new free apps.

  1. Click More info.
  2. Check that the app is SharkyClips-Setup-1.2.74.exe.
  3. Click Run anyway.

Want to be sure? Every release has a .sha256 file. In PowerShell, Get-FileHash SharkyClips-Setup-1.2.74.exe must show the same number.

More

Updates

Settings → Updates → Check for updates. SharkyClips installs the new version when you are not using it. What's new.

Uninstall

Windows Settings → Apps → SharkyClips → Uninstall. It asks if you also want to delete your settings; your videos are kept.

macOS and Linux

There is a one-command installer for macOS and a manual install for developers. They are less tested than Windows. See the install guide.
