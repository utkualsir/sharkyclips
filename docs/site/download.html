Install in three steps

  1. Download

    Click the download button. The file is called SharkyClips-Setup-1.2.76.exe.

  2. Install

    Open it and click Next, then Install. It takes about a minute. Does Windows show a blue message? See below.

  3. First start

    SharkyClips opens in your browser, asks for your language and checks your PC. Then it downloads the AI parts that fit your PC, once.

System requirements

How long does it take?

Measured on 28 November 2026 with real 1080p stream recordings (talking and gameplay), from import to 6 finished clips: speech recognition, finding the moments, AI titles and rendering.

StreamWith an NVIDIA graphics cardLight mode, processor only
1-hour streamabout 20 minabout 40 min (estimated)
3-hour streamabout 50 min (estimated)about 1 h 55 min (estimated)
  • Test PC: Intel Core i7-14650HX, 16 GB RAM, NVIDIA GeForce RTX 5070 Laptop GPU (8 GB). For Light mode the graphics card was not used (Settings → Performance → CPU only).
  • A slower processor takes longer: on a small 2-core laptop without a graphics card, a 17-minute video took about 16 minutes in Light mode.
  • SharkyClips works in the background. In Silent mode it pauses while you play a game, and goes on when you stop.
  • Times marked "estimated" are calculated from shorter real measurements (1 hour with the graphics card, 10 minutes in Light mode): the work grows with the length of the stream, and rendering is counted for 6 clips.

"Windows protected your PC"?

The installer is not signed with a paid certificate yet, so Microsoft Defender SmartScreen may warn about a new download. This is normal for new free apps.

  1. Click More info.
  2. Check that the app is SharkyClips-Setup-1.2.76.exe.
  3. Click Run anyway.

Want to be sure? Compare the SHA-256 of your file with the number at the top of this page.

macOS and Linux

On a Mac, one command installs everything. macOS and Linux are tested less than Windows.

  1. Download install.sh with the button below.
  2. Open Terminal and run bash ~/Downloads/install.sh. It shows what it will install (Homebrew, Python, FFmpeg and the AI parts) and asks for your Mac password if Homebrew is needed.
  3. Open SharkyClips from Applications.
