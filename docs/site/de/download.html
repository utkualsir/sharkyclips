SharkyClips herunterladen

Ein Installer mit allem drin. Keine Administratorrechte, keine Zusatzprogramme.

Für Windows herunterladenKostenlos · 375 MB · Version 1.2.74Alle Versionen
  • Version 1.2.74
  • Etwa 375 MB
  • Windows 10 / 11, 64 Bit
  • Kostenlos, kein Konto

In drei Schritten installieren

  1. Herunterladen

    Klick auf den Download-Knopf. Die Datei heißt SharkyClips-Setup-1.2.74.exe.

  2. Installieren

    Öffne sie und klick auf Weiter, dann auf Installieren. Das dauert etwa eine Minute. Zeigt Windows eine blaue Meldung? Siehe unten.

  3. Erster Start

    SharkyClips öffnet sich in deinem Browser, fragt nach deiner Sprache und prüft deinen PC. Dann lädt es einmal die KI-Teile herunter, die zu deinem PC passen.

"Der Computer wurde durch Windows geschützt"?

Der Installer ist noch nicht mit einem kostenpflichtigen Zertifikat signiert, deshalb kann Microsoft Defender SmartScreen vor einem neuen Download warnen. Das ist bei neuen kostenlosen Apps normal.

  1. Klick auf Weitere Informationen.
  2. Prüfe, dass die App SharkyClips-Setup-1.2.74.exe ist.
  3. Klick auf Trotzdem ausführen.

Willst du sichergehen? Jede Version hat eine .sha256-Datei. In PowerShell muss Get-FileHash SharkyClips-Setup-1.2.74.exe dieselbe Zahl zeigen.

Updates

Einstellungen → Updates → Nach Updates suchen. SharkyClips installiert die neue Version, wenn du es gerade nicht benutzt. Neuigkeiten.

Deinstallieren

Windows-Einstellungen → Apps → SharkyClips → Deinstallieren. Es fragt, ob du auch deine Einstellungen löschen willst; deine Videos bleiben erhalten.

macOS und Linux

Es gibt einen Ein-Befehl-Installer für macOS und eine manuelle Installation für Entwickler. Sie sind weniger getestet als Windows. Siehe die Installationsanleitung.
