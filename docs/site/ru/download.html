Системные требования

SharkyClips проверяет оборудование при каждом запуске и выбирает самую быструю рабочую настройку. Работает на обычных ПК: видеокарта ускоряет работу, но не обязательна.

«Система Windows защитила ваш компьютер»?

Установщик пока не подписан платным сертификатом, поэтому Microsoft Defender SmartScreen может предупредить о новой загрузке. Для новых бесплатных приложений это нормально.

  1. Нажмите Подробнее.
  2. Убедитесь, что приложение — SharkyClips-Setup-1.2.76.exe.
  3. Нажмите Выполнить в любом случае.

Хотите убедиться? Сравните SHA-256 вашего файла с числом вверху этой страницы.

macOS и Linux

На Mac всё устанавливается одной командой. macOS и Linux проверены меньше, чем Windows.

  1. Скачайте install.sh кнопкой ниже.
  2. Откройте Терминал и выполните bash ~/Downloads/install.sh. Он покажет, что будет установлено (Homebrew, Python, FFmpeg и части ИИ), и спросит пароль от Mac, если нужен Homebrew.
  3. Откройте SharkyClips из папки «Программы».

Ещё

Обновления

Настройки → Обновления → Проверить обновления. SharkyClips ставит новую версию, когда вы им не пользуетесь. Что нового.

Удаление

Параметры Windows → Приложения → SharkyClips → Удалить. Он спросит, удалить ли также настройки; ваши видео сохранятся.
