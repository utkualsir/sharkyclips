三步安装

  1. 下载

    点击下载按钮。文件名为 SharkyClips-Setup-1.2.74.exe。

  2. 安装

    打开它，点击下一步，然后点击安装。大约需要一分钟。Windows 显示蓝色提示？请看下方。

  3. 首次启动

    SharkyClips 会在浏览器中打开，询问你的语言并检查你的电脑。然后一次性下载适合你电脑的 AI 组件。

系统要求

SharkyClips 每次启动都会检查硬件，并选择能运行的最快设置。

“Windows 已保护你的电脑”？

安装程序尚未使用付费证书签名，因此 Microsoft Defender SmartScreen 可能会对新下载发出警告。对新的免费应用来说这很正常。

  1. 点击更多信息。
  2. 确认应用是 SharkyClips-Setup-1.2.74.exe。
  3. 点击仍要运行。

想确认一下？每个版本都有一个 .sha256 文件。在 PowerShell 中，Get-FileHash SharkyClips-Setup-1.2.74.exe 应显示相同的数值。

更新

设置 → 更新 → 检查更新。SharkyClips 会在你不使用时安装新版本。更新内容。

卸载

Windows 设置 → 应用 → SharkyClips → 卸载。它会询问是否也删除你的设置；你的视频会保留。

macOS 和 Linux

macOS 有一条命令即可完成的安装程序，开发者可以手动安装。它们的测试不如 Windows 充分。请参阅安装指南。
