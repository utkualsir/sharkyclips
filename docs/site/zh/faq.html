问题与解答

没找到你的问题？问问我们。

SharkyClips 真的免费吗？

是的。它是开源的（MIT 许可）。没有订阅、点数、水印和广告。AI 在你自己的电脑上运行，所以没有任何需要付费的地方。

SharkyClips 会把我的视频上传到别处吗？

不会。一切都在你的电脑上运行：语音识别、AI、寻找精彩时刻和制作短片。没有 SharkyClips 服务器，也没有追踪。只有你自己把短片分享到 YouTube、TikTok 或 Instagram 时，视频才会离开电脑。详情见隐私政策。

为什么上传 YouTube 需要我自己的 Google 项目？100 用户上限是什么？

要上传到 YouTube，应用需要 Google 登录。对于未经 Google 审核的登录，Google 将其限制为总共 100 个用户（Google 称之为用户上限）。如果所有 SharkyClips 用户共用一个登录，很快就会满。

所以下载版没有共享的 Google 登录。你需要连接一个属于你自己的免费 Google 项目。这样上限和每日上传配额都只属于你。它免费、不需要信用卡，只需一次大约 5 到 10 分钟。

如何连接我自己的 Google 项目？

在 SharkyClips 中：设置 → YouTube → 连接你自己的 Google 项目。向导会为你打开正确的 Google 页面：

  1. 创建一个项目（任意名称）。
  2. 启用 YouTube Data API v3。
  3. 设置同意屏幕（外部），并把自己添加为测试用户。
  4. 创建类型为桌面应用的 OAuth 客户端并下载其文件。
  5. 把这个文件拖入 SharkyClips，然后点击用 Google 连接。

Google 可能会提示应用未经验证：那是你自己的项目，可以继续。项目处于测试状态时，Google 会在 7 天后结束登录；将其设为正式版即可保持登录。完整指南。

如何设置 TikTok 助手扩展？

SharkyClips 助手是一个小小的浏览器扩展。它会填写你的 TikTok（如需要还有 Instagram）上传页面，并在发布前停下。

  • Microsoft Edge、Opera、Opera GX、Brave：无需任何操作。SharkyClips 打开上传页面时会自动添加助手。
  • Google Chrome：一步设置。SharkyClips 会显示简短指南：打开 chrome://extensions，开启开发者模式，点击加载已解压的扩展程序，然后选择 SharkyClips 显示的文件夹。
  • 第一次请你自己在那个浏览器窗口中登录 TikTok。SharkyClips 永远看不到你的密码。

助手只在 TikTok 和 Instagram 页面上运行，只与你电脑上的 SharkyClips 通信。没有它时，SharkyClips 会帮你复制文案，由你手动发布。

我的电脑能用吗？我没有游戏电脑。

能。你需要 Windows 10 或 11（64 位）和 8 GB 内存。不需要显卡。在没有 NVIDIA 显卡的电脑上，SharkyClips 会自动选择轻量模式：在处理器上运行的较小语音模型和较小 AI。速度较慢，但可以使用：在小型双核笔记本上，17 分钟的视频大约需要 16 分钟。有 NVIDIA 显卡会快很多。请查看系统要求。

它会让我的游戏变卡吗？

不会。在默认的安静模式下，你玩游戏或全屏观看时，SharkyClips 会暂停繁重的工作，并把显存还给游戏。你停下后它会继续。

Windows 提示“Windows 已保护你的电脑”。安全吗？

这是 SmartScreen 对尚未使用付费证书签名的新下载发出的警告。点击更多信息，然后点击仍要运行。你可以用版本附带的 .sha256 文件校验文件。分步说明。

我可以用哪些视频？

Twitch、YouTube 和 Kick 的录像（含弹幕回放）、大多数其他视频网站，或你电脑上的任何视频文件。长达数小时的直播也没问题。请只使用你拥有或有权使用的视频。

它会替我发布到 TikTok 和 Instagram 吗？

SharkyClips 会准备好一切，助手会填写上传页面，但点击发布的是你。Instagram 始终由你分享。连接你自己的 Google 项目后，YouTube 上传可以自动进行。

能在 Mac 或 Linux 上用吗？

主要平台是 Windows，提供一键安装程序。macOS 有一条命令即可完成的安装程序，Linux 和开发者可以手动安装，但它们的测试较少。请参阅安装指南。

如何报告问题或提出建议？

在应用中：设置 → 关于 → 发送反馈，或错误消息中的同一个按钮。它会打开一个 GitHub 表单，只填好应用版本和你的系统，不含其他内容。也可以使用联系页面。
