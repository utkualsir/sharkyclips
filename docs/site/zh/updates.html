新内容

SharkyClips 会自动更新：设置 → 更新。以下是最近几个版本的变化。

版本 1.2.762026-11-28

长的 Kick 视频又能完整导入了，Mac 安装文件回到了下载列表中，本地 AI 现在也可以使用 AMD Radeon 和 Intel Arc 显卡。

改进

  • AMD Radeon 和 Intel Arc 显卡： 负责写标题和挑选精彩时刻的本地 AI 现在可以在这些显卡上运行（前提是你的显卡受支持）。语音识别仍然在处理器上运行。如果想让所有工作都留在处理器上，请选择"设置" > "性能" > "处理设备" > "仅 CPU"。

修复

  • 长的 Kick 视频变成了只有 10 秒的项目。 下载中断时，应用把视频的一小段当成了整个视频。现在它只使用下载完成的文件。请再次导入同一个链接：下载会从中断的地方继续，声音和语音文字会根据完整视频重新生成。
  • 如果下载后视频仍有部分缺失，应用现在会告诉你，而不是默默地用一个更短的视频继续处理。
  • 下载中缺少 Mac 安装文件。 现在每个新版本都会附带 Mac 安装文件，和说明中写的一样。

版本 1.2.752026-11-27

看看你分享了多少：新的"上传"标签页会统计你在每个平台今天、本周和总共的上传。YouTube 上传上限现在会如实显示，重置时间也按你自己的时间显示。

新功能

  • "历史"页面中的"上传"标签页：你在 YouTube、Instagram、TikTok 以及手动发布的今天、本周和总共的上传，另有最近 14 天的图表。指向、点按或选中任意数字或柱条即可看到对应片段：时间、平台、链接和状态。
  • 使用你自己的 Google 登录时有精确计数："今天还剩 X / 100 次上传"，并显示重新开始的时间。

改进

  • 共享的 YouTube 上限如实显示。 使用 SharkyClips 内置的 Google 登录时，所有人共享一个每日上传额度，因此应用不再显示它无法知道的数字。它会显示"共享每日额度"、你今天上传了多少，以及额度按你的时间何时重新开始（太平洋时间 00:00，例如匈牙利的 09:00）。
  • 共享上限用完时，你会看到"今天的共享上传额度已用完。将在 … 重置。"以及两个按钮：手动上传，或使用你自己的 Google 登录。

修复

  • YouTube 表示当天的上传已用完后，你自己的计数会跳到 100。 现在它会保持真实的数字。

版本 1.2.742026-11-27

到处都是同一个标志，新增 11 种语言的网站，以及发送反馈的简单方式。TikTok 助手现在也可以从浏览器扩展商店安装。 另外，对话框不会再在屏幕外打开了。

显示详情

新功能

  • 发送反馈 / 报告问题。 在设置 → 关于中，以及每条错误消息里的“报告”按钮。它会打开一个 GitHub 表单，只填好应用版本和你的系统，不含其他内容。在你亲自提交之前不会发送任何内容。
  • 从扩展商店安装 SharkyClips 助手。 如果你从 Microsoft Edge 加载项或 Firefox 附加组件（即将上架）安装助手，只需连接一次：助手指南会显示一个 6 位数的连接码，把它输入助手的菜单即可。这样 Firefox 也能帮你填写上传内容。
  • 全新的网站，支持 11 种语言：介绍 SharkyClips 的功能、截图和简短演示、下载帮助（包括蓝色的“Windows 已保护你的电脑”提示）、问答以及更新说明。

改进

  • 到处都是同一个标志。 应用图标、时钟旁的图标、安装程序图片、启动画面、照片幻灯片的结尾和网站，现在都使用应用的经典外观。
  • 助手在浏览器工具栏中有一个小菜单，显示它是否已连接到 SharkyClips。
  • 同一浏览器里有两个助手（例如 SharkyClips 自带的副本和商店副本）时，不会再把页面填写两次：只有其中一个会填写。

修复

  • 滚动后的页面上，对话框会在屏幕外打开，部分被顶部栏挡住（例如设置页底部附近的助手指南）。现在它们总是在窗口中间打开。
  • 在手机上使用俄语时，设置中的一个选项会被截断（TikTok 的“半自动”）。现在很长的单词会在按钮内换行。

针对媒体库中新的照片幻灯片的一个小修复。

显示详情

修复

  • 幻灯片的项目链接（在媒体库和分享页面中）现在会打开幻灯片本身，而不是一个空的项目页面。

版本 1.2.722026-11-27

新功能：照片幻灯片。把 2 到 20 张照片（例如一项工程从之前到之后）做成适合 Reels、Shorts 和 TikTok 的竖屏视频。

显示详情

新功能

  • 照片幻灯片，简单模式和专业模式都有，主屏幕上有专门的按钮。拖入 2 到 20 张照片（JPG、PNG、HEIC 或 WebP）。照片按拍摄日期排序，你也可以拖动来改变顺序。
  • 干净的 9:16 视频：每张照片显示 3 秒（可在 2 到 5 秒之间选择），照片之间平滑切换（淡入淡出、滑动或缩放），并有缓慢、轻柔的缩放，绝不会裁掉重要部分。横着拍的照片会转正，宽照片会放在自身的模糊副本上完整显示，绝不拉伸。
  • 照片上的简短文字，例如“之前”“第 3 天”或“完成”。一个开关即可用你的语言添加“之前 / 进行中 / 完成”。文字会放在不被应用按钮遮挡的位置。
  • 结尾的 SharkyClips 动画标志（约 1.5 秒）。默认开启，也可以关闭。
  • 先预览，再导出，可使用显卡或处理器，所以较慢的电脑也能用。导出后：保存、打开文件夹，或带着你风格的标题和简介分享到 YouTube Shorts、Instagram 或 TikTok。不添加音乐：歌曲由你在 Instagram 或 YouTube 里添加。

版本 1.2.712026-11-27

一个小修复：同时发出的两个帖子在保存账号登录信息时不会再互相冲突。

显示详情

修复

  • 在 Windows 上 TikTok 或 Instagram 可能失败， 当两个帖子同时保存登录信息时。现在 SharkyClips 会稍等片刻再试一次。

版本 1.2.702026-11-26

现在 SharkyClips 会在你自己的浏览器中填写 TikTok 上传（视频、文案和设置），由你检查并亲自点击“发布”。分享也不会再卡在“正在分享…”了。

显示详情

新功能

  • TikTok 辅助上传（新的默认方式）： 点击“分享”，SharkyClips 会在你的浏览器（Chrome、Edge、Opera GX 或 Brave）中打开 TikTok Studio，添加视频，写好带话题标签的文案，选择“所有人”和“现在”，然后停下。页面和应用中的横幅会提示：“一切就绪。请检查后点击‘发布’。” SharkyClips 绝不会替你点击“发布”。
  • 发布后立即显示“已分享到 TikTok ✓”和链接。 如果 SharkyClips 无法确定，会问你一次：“你发布了吗？是 / 否”。
  • 只需在 SharkyClips 浏览器窗口中登录一次。 SharkyClips 永远看不到你的密码。如果 TikTok 要求验证，SharkyClips 会请你在浏览器中完成并等待。
  • 连续多个片段： 只有在你发布上一个之后，下一个片段才会打开，帖子之间会有短暂停顿。
  • Instagram Reels 也一样， 可在设置中选择。
  • 一个小小的浏览器助手 负责填写。Edge、Opera GX 和 Brave 会自动获得它。Chrome 需要一次简短的设置，SharkyClips 会展示每一步。
  • 发布队列： “取消所有待处理项”和新的“已取消”状态。

改进

  • 如果 TikTok 页面发生变化 而 SharkyClips 无法填写，你会立即得到手动发布的步骤（复制按钮、上传页面、文件夹）以及原因。完全手动发布在设置中仍然只需一键。
  • Firefox： 上传页面会在那里打开，由你手动发布，因为 Firefox 无法被填写。
  • Google 的用户上限： 当 Google 停止共享应用的新登录时，SharkyClips 会清楚说明，并带你前往创建自己的免费 Google 项目的步骤，包括点击“发布应用”。

修复

  • 当片段中仍能听到脏话时，“正在分享…”可能一直不动。 现在片段会说明它为什么在等待。
  • 无法制作的片段 现在会在一分钟后显示带“重试”的错误，而不是一直等待。
  • “重试”总会重新开始上传， 或清楚地告诉你为什么不能。
  • 你手动发布的平台绝不会拖住其他平台： 例如，对 TikTok 来说过长的文案不会再让 YouTube 停下。
  • 准备过程中停止的手动发布 现在会显示带“重试”的错误。

版本 1.2.692026-11-26

海军蓝和金色的外观重新成为默认，并保留了上次更新中更清晰的文字。新的“个性化”页面让你选择浅色、深色或“跟随 Windows”、四种外观、一个强调色和你自己的颜色。

显示详情

新功能

  • 在简单模式和 Pro 模式的设置中都有 个性化：选择浅色、深色或跟随 Windows。
  • 四种外观： 经典（海军蓝和金色，默认）、海洋（深海蓝配海玻璃青绿）、Shark Sign（上次更新的黄色外观）和高对比度。
  • 强调色： 从调色板中选择，或选择任何你喜欢的颜色。它会给按钮、打开的标签、进度条和高亮上色。你也可以让它显示在窗口标题栏上。
  • 你自己的颜色： 背景、面板、文字、次要文字、边框、按钮、链接、成功、警告、错误、被哔掉的词和字幕高亮，浅色和深色模式分别设置。
  • 始终容易阅读： 如果某个颜色让文字难以阅读，SharkyClips 会告诉你并自动修正（你可以关闭这个功能）。
  • 实时预览、 “恢复默认”，以及可以保存、再次打开或分享的主题文件。
  • “你已经用过这个视频” 现在一拖入或选好视频就会显示，还没生成任何片段之前。

改进

  • 每个界面都跟随你的颜色： 简单模式和 Pro 模式、窗口、小游戏、启动动画和登录页面。

修复

  • 上次更新后 Shark Sign 是唯一的外观。 现在它是四种之一，经典重新成为默认。

版本 1.2.682026-11-26

分享又能正常使用了，而且现在很简单：拖入视频，勾选 YouTube、Instagram 或 TikTok，点“分享”，剪辑就会立即发布。每个剪辑都会清楚地告诉你它已发布（附链接），或者哪里出了问题。

显示详情

新功能

  • 立即分享。 你选择的所有剪辑都会立即发布。不再有每日上限设置，也不再安排到之后几天。唯一的限制是 YouTube 今天允许的数量，你随时能看到“今天还剩 X 次 YouTube 上传”。
  • 超过 YouTube 今天允许的数量？ 由你选择：现在手动上传剩下的、放到明天，或者自己选一天。
  • 三步完成的简单模式。 拖入视频，在一个大网格中看到所有 Shorts，勾选平台，点“分享”。屏幕上没有别的东西。
  • 每个剪辑都有消息。 “已分享到 YouTube ✓”并附链接，在应用中和 Windows 通知中显示，或者清楚说明哪里出了问题。
  • 手动上传，适用于每个剪辑和每个平台。SharkyClips 会保存合适的视频，显示标题、描述和话题标签，每项都有复制按钮，并打开上传页面和文件夹。
  • 上传历史。 新页面列出你分享过的每个剪辑：日期、游戏、剪辑、平台和链接。可以搜索，删除项目后也会保留。
  • “我已经上传过这个了吗？” SharkyClips 认得你用过的每个视频，即使换了名字。如果你再次导入，它会告诉你这些剪辑何时、在哪里分享过。
  • 释放空间。 剪辑分享完后，一个按钮就能删除直播视频和生成的文件，并先显示能腾出多少 GB。你的帖子和历史会保留。
  • 每个视频都可以选择标题语言。

改进

  • 为播放量而写的标题： 全部大写并使用你语言的正确字母，配上合适的表情，YouTube 上加 #Shorts。Instagram 最多 5 个话题标签。
  • 每个视频发布前都会检查（9:16、时长、格式、大小），需要时自动修正。
  • TikTok 现在默认手动发布， 因为自动发布可能在 TikTok 的验证处停下。你仍然可以开启自动发布。
  • Instagram 的 4 小时间隔现在只是提醒。 你仍然可以发布。
  • Pro 模式与简单模式的分享方式相同。

修复

  • 不再有默默等待的剪辑。 如果 YouTube 未连接、今天的上传次数已用完，或者你玩游戏时 SharkyClips 暂停了，剪辑会说明原因。
  • 被 YouTube 保留为私享的视频 现在总会显示为私享，并有按钮可在 YouTube Studio 中打开。
  • SharkyClips 以前用旧数字计算 YouTube 上传次数， 每天上传几次后就停了。现在使用 YouTube 当前的限制：每天 100 次上传。
  • 如果 Google 阻止应用的新登录（其 100 位用户上限），SharkyClips 现在会说明情况以及你可以怎么做。

版本 1.2.672026-11-26

针对 Windows 的小修复：当 YouTube 不再接受你的登录时，即使 Windows 暂时占用登录文件，SharkyClips 现在也总会提示你重新连接。

显示详情

修复

  • “重新连接”总会显示。 在 Windows 上，其他程序可能会短暂占用 YouTube 登录文件，导致上传失败却没有提示你重新连接。现在 SharkyClips 会稍等片刻再试，并总是显示提示。

版本 1.2.662026-11-22

现在分享大量片段很简单：打开“分享片段”，一次看到一个视频的所有片段和清楚的状态，勾选想要的，一次分享。每日上限保护你的账号，其余的会自动安排到之后几天。

显示详情

新功能

  • 分享片段。 一个大屏幕显示视频的所有片段：大图、悬停或点按即可播放、时长、爆款分和标题。每个片段都清楚显示：未分享、已排期（带日期和时间）、已分享（带平台图标和帖子链接）或失败（带“重试”按钮）。
  • 同一片段绝不发两次。 已分享的片段会变灰。“全部”“未分享”“已分享”标签帮你看到还剩什么。如果你选了已经发出的片段，SharkyClips 会提醒你，并只发到还没发过的地方。
  • 多选，一次分享。 每张卡片上有勾选框，还有“全选”和“选择未分享的”，以及一个大大的“分享所选”按钮。每张卡片也有自己的“分享”按钮。
  • 每日上传上限。 默认每天 5 个片段，可在设置中选择 1 到 6 个（6 个是 YouTube 免费额度允许的数量）。你总能看到还剩多少，例如“今天还剩 3/5”。选得更多时，其余的会自动安排到之后几天。
  • 一个简单的流程。 点“分享”后，为所有片段一次选择平台（只显示已连接的；其他的有“连接”按钮）。“逐个编辑”可修改每个片段的标题、描述、话题标签和平台。然后摘要会显示什么发到哪里、什么时候发，以及占用今天多少次上传。最后点“发布”。
  • 看着它完成。 进度面板显示这一批的每个片段，以及它在每个平台上的状态。

改进

  • Instagram 依然安全。 Instagram 帖子之间仍至少间隔 4 小时；摘要会显示顺延后的时间。Instagram 的手动模式和你的其他平台设置保持不变。
  • 撤销。 把片段移出计划会等几秒，并显示“撤销”按钮。
  • 记住你的选择。 上次选的平台下次会自动选中。
  • 简单模式和专业模式一样好用， 按钮大，也能用键盘：Esc 清除选择，Ctrl+A 选中所有显示的片段。

版本 1.2.652026-11-22

SharkyClips 换上了新外观：深海的颜色、鲨鱼警示牌的黄色，每个界面的文字都更清楚。所有功能和以前一样。

显示详情

新功能

  • 处处都是新外观。 所有界面、窗口和提示都改用深海色，主按钮只用一种明亮的黄色。主按钮、片段卡片和窗口都有一个小小的切角，像鲨鱼的鳍。
  • 新的标志和应用图标。 鲨鱼鳍现在放在一块黄色警示牌上。安装程序、启动动画和网站也都换成了新外观。

改进

  • 更容易阅读。 整个应用只用一套清晰的字体，标题更大更粗，时间和数字使用等宽字体，排列整齐。
  • 字体离线也能用。 字体现在内置在应用里，没有网络时看起来也一样，不会从其他网站加载任何东西。
  • 颜色更清楚。 黄色现在只表示主要操作和最佳时刻。开启的开关是绿色，警告是橙色。
  • 更安静的进度界面。 "正在寻找你的最佳时刻"现在在一条线上显示带编号的步骤，正在进行的步骤有一个进度条。
  • 专业模式更紧凑。 编辑器界面的空白更少，屏幕上能放下更多片段。
  • 更安静的动效。 打开页面时只有页面本身会动，列表不再一个个滑入。

更早的版本和每个版本的安装程序都在 GitHub 上。
