SharkyClips をダウンロード

必要なものがすべて入ったインストーラー 1 つ。管理者権限も追加のプログラムも不要です。

Windows 版をダウンロード無料 · 375 MB · バージョン 1.2.74すべてのバージョン
  • バージョン 1.2.74
  • 約 375 MB
  • Windows 10 / 11、64 ビット
  • 無料、アカウント不要

3 ステップでインストール

  1. ダウンロード

    ダウンロードボタンをクリックします。ファイル名は SharkyClips-Setup-1.2.74.exe です。

  2. インストール

    開いて「次へ」、続いて「インストール」をクリックします。1 分ほどかかります。Windows に青いメッセージが出たら？下をご覧ください。

  3. 初回起動

    SharkyClips がブラウザーで開き、言語を聞いて PC を確認します。その後、PC に合った AI の部品を一度だけダウンロードします。

システム要件

SharkyClips は起動のたびにハードウェアを確認し、動作する中で一番速い設定を選びます。

「Windows によって PC が保護されました」？

インストーラーはまだ有料の証明書で署名されていないため、Microsoft Defender SmartScreen が新しいダウンロードとして警告することがあります。新しい無料アプリではよくあることです。

  1. 詳細情報をクリックします。
  2. アプリが SharkyClips-Setup-1.2.74.exe であることを確認します。
  3. 実行をクリックします。

念のため確認したいときは：各バージョンには .sha256 ファイルがあります。PowerShell で Get-FileHash SharkyClips-Setup-1.2.74.exe を実行すると、同じ値が表示されるはずです。

その他

アップデート

設定 → アップデート → 更新を確認。SharkyClips は使っていないときに新しいバージョンを入れます。更新情報。

アンインストール

Windows の設定 → アプリ → SharkyClips → アンインストール。設定も削除するか聞かれます。動画は残ります。

macOS と Linux

macOS には 1 コマンドのインストーラー、開発者向けには手動インストールがあります。Windows ほどはテストされていません。インストールガイドをご覧ください。
