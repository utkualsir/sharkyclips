質問と回答

質問が見つからない場合はお問い合わせください。

SharkyClips は本当に無料ですか？

はい。オープンソース（MIT ライセンス）です。サブスク、クレジット、透かし、広告はありません。AI は自分の PC で動くので、支払うものは何もありません。

SharkyClips は私の動画をどこかにアップロードしますか？

いいえ。すべてあなたの PC で動きます：音声認識、AI、見どころ探し、クリップ作り。SharkyClips のサーバーも追跡もありません。動画が PC から出るのは、あなた自身が YouTube、TikTok、Instagram にクリップを共有したときだけです。詳しくはプライバシーポリシーをご覧ください。

YouTube にはなぜ自分の Google プロジェクトが必要なのですか？100 ユーザーの上限とは？

YouTube にアップロードするには、アプリに Google ログインが必要です。Google は審査していないログインを合計 100 ユーザーまでに制限しています（Google はこれをユーザー上限と呼びます）。SharkyClips の全ユーザーで 1 つのログインを共有すると、すぐにいっぱいになってしまいます。

そのため、ダウンロード版には共有の Google ログインがありません。代わりに自分専用の無料 Google プロジェクトを接続します。そうすれば上限も 1 日のアップロード枠もあなただけのものです。無料で、クレジットカードも不要、1 回だけ約 5〜10 分で済みます。

自分の Google プロジェクトはどうやって接続しますか？

SharkyClips で：設定 → YouTube → 自分の Google プロジェクトを接続。ガイドが正しい Google のページを開いてくれます：

  1. プロジェクトを作成します（名前は自由）。
  2. YouTube Data API v3 を有効にします。
  3. 同意画面（外部）を設定し、自分をテストユーザーに追加します。
  4. 種類がデスクトップアプリの OAuth クライアントを作成し、そのファイルをダウンロードします。
  5. そのファイルを SharkyClips にドロップし、「Google で接続」をクリックします。

Google がアプリは未確認だと表示することがありますが、自分のプロジェクトなので続行して大丈夫です。プロジェクトがテスト中の間は 7 日でログインが切れます。本番環境にするとログインが保たれます。詳しいガイド。

TikTok ヘルパー拡張機能はどう設定しますか？

SharkyClips ヘルパーは小さなブラウザー拡張機能です。TikTok（希望すれば Instagram も）のアップロードページを入力し、投稿の前で止まります。

  • Microsoft Edge、Opera、Opera GX、Brave：何もする必要はありません。SharkyClips がアップロードページを開くときに自動でヘルパーを追加します。
  • Google Chrome：設定が 1 回だけ必要です。SharkyClips が短いガイドを表示します：chrome://extensions を開き、デベロッパー モードをオンにし、「パッケージ化されていない拡張機能を読み込む」をクリックして、SharkyClips が示すフォルダーを選びます。
  • 最初だけ、そのブラウザーのウィンドウで自分で TikTok にログインします。SharkyClips がパスワードを見ることはありません。

ヘルパーは TikTok と Instagram のページでのみ動作し、PC の SharkyClips とだけ通信します。ヘルパーがなくても、SharkyClips が説明文をコピーしてくれるので手動で投稿できます。

私の PC で動きますか？ゲーミング PC は持っていません。

はい。Windows 10 または 11（64 ビット）と 8 GB のメモリが必要です。GPU は不要です。NVIDIA の GPU がない PC では、SharkyClips が自動でライトモードを選びます：プロセッサーで動く小さめの音声モデルと小さめの AI です。遅くなりますが動きます：小さな 2 コアのノート PC で、17 分の動画が約 16 分です。NVIDIA の GPU があればずっと速くなります。システム要件をご覧ください。

ゲームが重くなりませんか？

なりません。初期設定のサイレントモードでは、プレイ中や全画面で何かを見ている間は重い処理を止め、ビデオメモリをゲームに返します。やめると再開します。

「Windows によって PC が保護されました」と表示されます。安全ですか？

これは、まだ有料の証明書で署名されていない新しいダウンロードに対する SmartScreen の警告です。詳細情報、次に実行をクリックしてください。バージョンの .sha256 ファイルでファイルを確認できます。手順を見る。

どんな動画が使えますか？

Twitch、YouTube、Kick の録画（チャットのリプレイ付き）、ほかのほとんどの動画サイト、または PC 上の動画ファイル。数時間の長い配信も大丈夫です。自分の動画か、使う権利のある動画だけを使ってください。

TikTok や Instagram に代わりに投稿してくれますか？

SharkyClips がすべて準備し、ヘルパーがアップロードページを入力しますが、投稿ボタンを押すのはあなたです。Instagram は常にあなたが共有します。自分の Google プロジェクトを接続すれば、YouTube へのアップロードは自動にできます。

Mac や Linux でも動きますか？

メインは Windows で、ワンクリックのインストーラーがあります。macOS には 1 コマンドのインストーラー、Linux と開発者向けには手動インストールがありますが、テストは少なめです。インストールガイドをご覧ください。

不具合の報告やアイデアの提案はどうすればいいですか？

アプリで：設定 → 情報 → フィードバックを送る、またはエラーメッセージにある同じボタン。アプリのバージョンとシステムだけが入力された GitHub のフォームが開きます。お問い合わせページも使えます。

まだ解決しませんか？

不具合を報告するか、GitHub の質問をすべてご覧ください。
